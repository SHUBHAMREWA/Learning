What is Traversal?

Traversal is a method used in arrays to access or retrieve all elements one by one.
Example: For an array like [2, 3, 4, 5], if we want to access all the data, we use traversal.

  • We can use loops like for, while, or JavaScript methods like forEach() to traverse data.
  • We can also use recursion to traverse through the array.
